# Recipe-Hub
### Recipes provided by TheMealDB api
## This is a simple web app for discovering new recipes
## Features
- Search your dish
- Categorized dishes as chicken beef veg and desserts.
- Get a random recipe
- it includes images ingredients and more.

## Tech
- HTML
- CSS
- JS
- TheMealDb public api

## How it works
The app diff url api requests to the meal db public api and it responds. it is converted into json.
